FALSE ALIBI

事件前後の行動記録を並べ替え、犯行手段を見抜き、最後に証言の矛盾を突き付ける。探偵として事件を解き明かす、推理テーマのロジックパズル。

犯行現場・被疑者・証言は最初から提示されます。あなたは捜査資料を集め、矛盾を組み立てて最後の一言を突き付ける立場です。資料を見すぎるほど捜査点は増えます。

  • 1ROUND 1 / 行動記録：監視記録と目撃情報から、現場付近に現れた4人の順番を整理します。
  • 2ROUND 2 / 犯行手段：現場の痕跡から、犯行に使われた手段・道具を特定します。
  • 3ROUND 3 / 証言照合：行動記録と犯行手段を重ね、1つだけ矛盾する証言を突き止めます。
設計メモ：
ROUND1とROUND2は独立して解けます。最後のROUND3だけは、行動記録と犯行手段の両方がそろって初めて証言の矛盾が見えてきます。
スコア式：使った捜査資料の合計点。低いほど鮮やかな解決。
